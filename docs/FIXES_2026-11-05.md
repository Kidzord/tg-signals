# Исправления по bug-hunt 2026-11-05

Отчёт по аудиту (4 ревью + ruff + проверка по коду) и что исправлено.
Тесты: **411 passed**, `ruff check .` — чисто. PowerShell-скрипты проверены
парсером. Процессы перезапущены после правок (4 бота, subbot, monitor, heartbeat,
autoposts, shadow).

## P0 — безопасность и дубли

- **Утечка токена.** `config.redact()` вырезает `bot<id>:<token>` из ошибок
  `requests`; `tg.py` и `health.py` используют его. `/health/detailed` теперь
  может требовать `HEALTH_TOKEN` (заголовок `X-Health-Token` или `?token=`).
- **Webhook fail closed.** `WEBHOOK_SECRET` больше не падает в `change-me`;
  пустое значение или дефолтная заглушка отключают `/tv/{secret}` и
  `/consensus/{secret}`. В `.env.example` секрет пустой.
- **Дубли bot.py.** Добавлен `bot_lock_<symbol>_<strategy>.json` с PID:
  второй экземпляр на тот же символ/стратегию не стартует. Lock включён и для
  режима `bot.py classic` (раньше только для запуска без аргументов).
  Heartbeat пишется сразу при старте (до MT5) и при исключении шага
  (`ok:false` + error), поэтому watchdog больше не принимает медленный старт
  за мёртвый процесс.
- **start_all lock** — атомарный `CreateNew` с PID, отрицательный возраст
  (съехавшие часы) считается протухшим; удаляется только свой lock.
- **Health state files** — проверяются реальные `bot_state_*.json`, а не
  несуществующие `XAUUSD/GOLD`.

## P1 — доставка и деньги

- Ожидание карточки входа больше не расходует `attempts`
  (`mark_delivery_retry(count_attempt=False)`).
- `poll_results` не теряет результат, если вход ещё не в outbox: молодой
  результат (<1 ч) остаётся в очереди, watermark не двигается.
- `_read_queue` читает `ts >= last_ts` (равные timestamps не теряются).
- Групповой 429 теперь тоже упирается в лимит 6 попыток и уходит в `failed`.
- `_notify_result` при неудачном reply шлёт сообщение без reply — уведомление
  не теряется, даже если карточку удалили.
- CRT с двумя целями закрывает остаток как `tp` (финальное закрытие), поэтому
  сделка попадает в `trades.jsonl`, трек-рекорд и `risk_guard`.
- `note_trade` вычитает `costs.cost_r` (net-R), как в бэктестах/WFA.
- `bot.simulate` при `entry_delay` не управляет баром до входа и не открывает
  сделку, если цена уже прошла стоп (раньше могла получиться +1R).
- Склейка итога в группе: только `pending` (не `sending`), только финальные
  события (TP1/TP2 идут отдельным сообщением), перед отменой вход перечитывается
  и не отменяется, если итог уже вписан; маркер ТФ больше не хардкодит `M15`.

## P1 — торговое ядро и research

- `range_v2`: ключи уровней/флипов/`max_stops` — 5 знаков вместо `round(...,2)`;
  на EURUSD 1.0801 и 1.0849 больше не склеиваются. `max_stops` ключуется по
  цене уровня, а не по entry.
- Гэп через стоп исполняется по открытию (bot.py live+simulate, range_v2,
  mr_probe, scalp_probe); в mr/scalp добавлено «открытие за целью» раньше стопа.
- `shadow.py`: range-кандидат считается **net** (спред) и получает реальную
  `exit_price` из R/риска; real-yield фильтр использует **предыдущий** день.
- `regime_probe`: DXY/VIX/нефть/real yield/broad dollar — только закрытие
  предыдущего дня, без same-day lookahead; защита от бесконечного поиска даты.
- `prop.py`: те же ATR-правила, что у live range (stop_atr=1.0, tp 3R,
  max_stops=0), и защита от деления на ноль при нуле сделок.
- `grid_probe`: отказывается работать не на XAU (CONTRACT_OZ=100), при
  `balance<=0` останавливает прогон, а не продолжает с отрицательным счётом.
- `bot.simulate`: цель на открытии обрабатывается раньше стопа; сделка,
  открытая на последнем баре окна, фиксируется как `TIME_END` и больше не
  выпадает из WFA/портфеля.
- `crt/sonar/ict2022/pdl_sweep`: гэп через стоп/цель исполняется по open;
  CRT больше не пишет гэп-стоп как 0R.
- `axis_sweep`: база берётся из фиксированного `wf.STRATEGIES[name]["grid"]`
  (range_short получает `side=short`, range_live — свой TP/ER).
- `portfolio_backtest`: спреды из `costs.symbol_spread`, а не хардкод.
- `shadow`: TP/SL на последнем баре считается закрытой сделкой, `open` — только
  MTM-по-времени.
- `monitor.bat`/`heartbeat.bat`/`scheduler.bat`/`shadow.bat`: лог через
  `Add-Content` (файл не держится открытым, ротация возможна), старые hb-файлы
  (7+ дней) больше не алертят вечно.

## P2 — ops

- `monitor.py`: `set-healthcheck` без URL больше не поднимает второй демон;
  счёт ботов не удваивается из-за powershell-обёртки; `.env` пишется атомарно;
  алерт без `OWNER_CHAT_ID` не помечается доставленным.
- `start_all.ps1`: `$DIR` от `$PSScriptRoot` вместо хардкода; путь refresh
  экранируется; `BOT_NO_PAUSE=1`.
- `bot.bat`/`subbot.bat`: не оставляют окно на `pause` при фоновом запуске,
  возвращают реальный код выхода Python.
- `refresh_external.ps1`: `curl -f`, проверка HTML-ответа, штамп пишется только
  после успешной загрузки.
- `heartbeat.py`: неизвестный аргумент не запускает второй демон.
- `risk_guard`: non-numeric `ts/r` не роняют цикл монитора.
