# Candle Range Theory (CRT) — методика и механические правила

Реализация: `crt.py`, стратегия `STRATEGY=crt` (вход через `bot.py`).
Документ фиксирует правила **до** форвард-прогона: параметры можно менять,
но тогда это другой тест.

## Что это и откуда

CRT — розничная ICT-производная. Автор, которого чаще всего называют
создателем термина: **RomeoTPT** (@Romeotpt). Модель — переупаковка
ликвидностных свипов («turtle soup» из *Street Smarts* Рашке/Коннорса),
Power of 3 (accumulation → manipulation → distribution) и премиум/дисконт
диапазона. Академического или институционального статуса у модели нет.

Ключевая идея: свеча старшего ТФ задаёт диапазон, следующая свеча его
прокалывает (снимает стопы), возвращается внутрь — и цена идёт к
противоположной границе.

## Каноническая модель (3 свечи, старший ТФ)

Пусть C1 — предыдущая закрытая свеча старшего ТФ (по умолчанию H4):

```
CRH = C1.high,  CRL = C1.low,  R = CRH - CRL,  EQ = (CRH + CRL) / 2
```

* **C2 — манипуляция.** Прокалывает ровно одну границу C1 и закрывается
  обратно внутрь диапазона:
  * свип низа (`C2.low < CRL`) + закрытие внутри → **лонг** к CRH;
  * свип верха (`C2.high > CRH`) + закрытие внутри → **шорт** к CRL.
  * закрытие снаружи = настоящий пробой, классический сетап не наш.
* **C3 — распределение:** ход к противоположной границе. В боте закрытие
  C3 не требуется: вход по закрытию C2 (как в системных разборах
  agm/LuxAlgo/ProEA). Иначе сигнал опаздывает на целую свечу.

### Сделка

| Элемент | Правило |
|---|---|
| Вход | рынок на первом баре рабочего ТФ после закрытия C2 |
| Стоп | за экстремум свипа C2 ± `CRT_STOP_BUF` × ATR(14) рабочего ТФ |
| Цель 1 | EQ (середина C1), закрываем `CRT_P1` (50%), стоп в БУ |
| Цель 2 | противоположная граница C1, остаток |

### Фильтры (все вынесены в параметры)

| Параметр | Смысл | Дефолт |
|---|---|---|
| `CRT_RANGE_TF` | ТФ диапазона C1 | `240` (H4) |
| `CRT_MIN_RANGE_ATR` | диапазон C1 ≥ N × ATR(14) старшего ТФ | 0.8 |
| `CRT_MAX_BODY` | тело C1 ≤ N доли диапазона (отсечь марубозу) | 0.85 |
| `CRT_MAX_SWEEP` | прокол C2 ≤ N доли диапазона (иначе стоп широк) | 0.40 |
| `CRT_MIN_RR` | R:R до противоположной границы | 1.0 |
| `CRT_MIN_R1` | минимум R до середины для частичного выхода | 0.30 |
| `CRT_DUAL_FILTER` | свип обеих границ — не сетап | 1 |
| `CRT_C1_COLOR` | C1 должна быть против сделки | 0 |
| `CRT_SESSION` | окно времени сервера | выкл. |

### Вариант `failed`

Отдельная стратегия, не фильтр: если C2 **закрылась снаружи** C1 — торгуем
продолжение пробоя. Стоп — за пробитым уровнем (CRH/CRL) минус буфер,
цель `CRT_TP_R` (по умолчанию 1R). Включается `CRT_VARIANT=failed`.

## Что говорят источники (и где расходятся)

Определения гуляют: «C1/C2/C3» в разных разборах означают разное, а часть
статей — SEO-контент. Практически важные развилки:

1. **C2 должна закрыться внутри или достаточно вернуть фитиль?** Мы берём
   строгое ядро: закрытие внутри (ProEA, agm, GEKO).
2. **Нужна ли C3?** Часть авторов требует закрытия C3 за high/low C2 или за
   EQ. Мы входим по C2 — иначе сигнал приходит позже.
3. **Двойной свип.** Большинство точных разборов выбрасывают; у нас это
   `CRT_DUAL_FILTER`.
4. **Цвет C1.** Часть авторов требует C1 против направления сделки; у нас
   выключено (спорно и режет выборку).
5. **Цель.** Середина диапазона как TP1 — у системных разборов; некоторые
   учат сразу на противоположную границу.

## Важная оговорка про эдж

Самый прозрачный публичный тест, который удалось найти, — «Edge or Myth #7»
(`edge-or-myth-crt` выше): XAUUSD M1 2020–2026, закрытые свечи, спред и
проскальзывание. Классический CRT на H1 с диапазоном 08:00 NY дал 563 сделки,
44.8% прибыльных, −0.061R в среднем, PF 0.89. Вариант `failed` на H4 дал
+0.052R (PF 1.11). То есть **классическая модель в популярном виде на золоте
после издержек эджа не показала**; `failed` — слабый положительный кандидат,
и то в основном за счёт растущего золота.

Поэтому:
- это исследовательский кандидат, а не подтверждённая стратегия;
- перед запуском в живую — прогнать `bot.py scan` на своём брокере и
  WFA-протоколом (IS → OOS → WFA), как для остальных стратегий;
- варианты `classic` и `failed` тестируются отдельно и не смешиваются.

## Структурные стоп и тейк (по сильным зонам)

Вместо геометрии свечи стоп и тейк можно привязать к сильным уровням
старшего ТФ. Используется существующий механизм `range_v2.zones_for_chart`
(зоны по телам свечей, минимум `CRT_LEVEL_TOUCHES` касаний, только по
закрытым барам — без заглядывания вперёд):

- `CRT_SL_MODE=level` — для лонга берётся ближайшая поддержка ниже входа,
  для шорта — сопротивление выше; буфер тот же (`CRT_STOP_BUF`). Уровень
  ближе `CRT_STOP_MIN_ATR` ATR считается шумом, дальше `CRT_STOP_MAX_ATR` —
  слишком широкий риск. Если подходящего уровня нет — стоп за свипом C2.
- `CRT_TP_MODE=zone` — финальная цель тянется к ближайшей противоположной
  зоне в коридоре `CRT_TP_MIN_R … CRT_TP_MAX_R`. Если зоны нет — остаётся
  противоположная граница C1 (classic) или 1R (failed). Частичный выход на
  середине диапазона сохраняется, если она впереди и до финальной цели.

Как часто срабатывает (H4/M15, 3 инструмента): стоп по уровню — в 2–9%
сигналов, тейк по зоне — в 16–35%.

Результат: **улучшения нет.** На единственной прибыльной связке
(XAUUSD H4/M15 failed) структурный вариант дал +0.06…+0.08R после спреда
против +0.135R у базового: зона обычно дальше границы C1, и падение
доли дошедших сделок перевешивает рост R. На H1/M5 картина та же
(USDCAD failed +0.058 → +0.040R; XAU +0.003 → −0.005R). У классики
структурный тейк местами чуть улучшает минус, но нигде не выводит в плюс.

Поэтому дефолты оставлены `sweep` / `range`; режимы доступны для
экспериментов, но в live без отдельного WFA их включать не нужно.

## Фиксированный риск 0.5% от баланса (банк $5000)

Денежная симуляция: риск каждой сделки — 0.5% **текущего** баланса
(≈$25 на старте), размер позиции подбирается под расстояние до стопа,
результат компаундится, спред вычитается из R как `спред / стоп_в_цене`.
Команда: `CRT_BANK=5000 CRT_RISK_PCT=0.5 python crt.py`.

Сначала выяснилась важная вещь: при таком сайзинге сделки, где гэп прижал
вход почти к стопу, получают крошечный риск в цене — и спред превращается
в десятки R. Одна такая сделка на XAUUSD M5/H1 стоила −43% счёта. Поэтому
добавлен обязательный фильтр `CRT_MIN_RISK_ATR=0.15`: стоп ближе 0.15 ATR
рабочего ТФ не торгуется. Проверка стоит и в бэктесте (по фактической цене
входа следующего бара), и в живом шаге бота.

Плюс XAUUSD H4/M15 `failed` (+31.9R, «+0.153R на сделку») оказался
артефактом нормировки: 9 сделок из 208 с микро-стопом после гэпа дали

при фиксированном риске это −1.5% за 320 дней, а не +10%.

**единственный положительный результат — USDCAD, диапазон H1, вход M5,
