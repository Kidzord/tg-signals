# Аудит баров: второй фид и сверка качества

Дата: 2026-11-04. Инструмент: `tools/bar_audit.py`.

## Зачем

Live, research и карточки берут OHLC из одного терминала MT5. Аудит отвечает
на два вопроса: нет ли дыр/дублей внутри фида и совпадает ли он с независимым
источником. Торговлю инструмент не трогает — только читает бары.

## Второй терминал

Для сверки поставлен отдельный демо-терминал Exness:

* путь: `C:\MT5-Exness\terminal64.exe` (portable, отдельная папка);
* сервер: `Exness-MT5Trial11`, счёт демо, баланс $11 000;
* тикеры Exness имеют суффикс `m`: `XAUUSDm`, `EURUSDm`, `AUDUSDm`, `USDCADm`;
* логин/пароль хранятся только в терминале; файл `.mt5_second.ini` после
  первого входа удалён и в git не попадает.

Основной терминал: `C:\Program Files\MetaTrader 5\terminal64.exe`.

## Команды

```powershell
# Внутренняя сверка: M15 против M15, собранного из M1
python tools/bar_audit.py --symbol XAUUSD --bars 500

# Сверка с Exness
python tools/bar_audit.py --symbol EURUSD --other-symbol EURUSDm --mode mt5 `
  --mt5-native "C:\Program Files\MetaTrader 5\terminal64.exe" `
  --mt5-path "C:\MT5-Exness\terminal64.exe" --bars 1000

# Выгрузить бары в CSV / сравнить CSV или Twelve Data
python tools/bar_audit.py --symbol XAUUSD --dump xau.csv
python tools/bar_audit.py --symbol XAUUSD --mode csv --file xau.csv
python tools/bar_audit.py --symbol EURUSD --mode twelvedata
```

Код возврата 1 — дубли, разрывы внутри фида или цена вне допуска. Пропуски
между разными брокерами (разные сессии и выходные) по умолчанию считаются
информационными; `--strict` делает их ошибкой.

|---|---:|---:|---:|---:|---:|
| EURUSD | 995 | 0.004% | 0.071% | 0.219% | 0 |

| USDCAD | 995 | 0.005% | 0.059% | 0.202% | 0 |

Внутренняя сверка (M15 из M1): пропусков, дублей и расхождений close — 0 на
всех четырёх символах. У XAUUSD есть регулярные паузы брокера 75–135 минут
в 00:00–01:00; у FX — пятничное закрытие в 23:00 с нулевым диапазоном.

## Что показало золото

Выбросы XAUUSD сосредоточены только в 21–23 октября: 21.10 — 3 бара,
22.10 — 10, 23.10 — 6. С 26 октября медиана 0.003–0.004%, максимум 0.427%,
а 2–4 ноября максимум 0.013%. То есть **текущие фиды согласованы**, а
расхождение — исторический участок: похоже на часовой сдвиг сегмента у
одного из источников.

Практический вывод: на данных 21–23 октября 2026 нельзя строить выводы WFA
без отдельной проверки; текущий live-период чистый.

## Ограничения

* Exness отдаёт M1 порциями до 50 000 баров; запрос 100 000 возвращает пусто.
* Сдвиг часов подбирается целыми часами; минутные сдвиги проверены вручную
  (0 минут — оптимум).
* Разные брокеры могут иметь разные сессии и пятничное закрытие — это не
  потеря данных.
