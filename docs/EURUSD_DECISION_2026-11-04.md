# EURUSD выведен из live (2026-11-04)

Решение: убрать EURUSD из `start_all.ps1`, бот остановлен. Код, параметры и
тесты остаются — символ можно вернуть после выполнения критериев ниже.

## Почему

| Проверка | Результат |
|---|---|
| WFA classic-флота (не EURUSD) | для контекста: 181 сделка, +14.92R, 14/27 фолдов |
| WFA EURUSD (2026-11-03) | OOS +30.28R, но 13/22 активных фолдов (59%) — «не проходит» |
| Python range, native, 24.08–04.11, trend=off | 40 сделок, 0.00R, net −2.00R |
| Python range, native, 24.08–04.11, trend=with | 29 сделок, −1.00R, net −2.45R |
| Python range, Exness, 24.08–04.11, trend=off | 13 сделок, −1.00R, net −1.65R |
| RangeBotEA, Exness, 20.08–24.10, er=off/tp=3 | 35 сделок, −5.7%, PF 0.60 |
| Live | 1 сделка, −1R |

Последние 2.5 месяца на двух независимых фидах дают минус. WFA не проходит
порог консистентности. Первый live-вход тоже в стоп.

`RangeBotEA` нельзя использовать как аргумент напрямую: он даёт 35 сделок
против 13 у Python на том же окне, то есть порт зон/целей расходится. Это
дополнительный флаг нестабильности, а не доказательство.

## Критерии возврата

1. Порт тренд-фильтра (`RANGE_TREND=with`, H4 EMA200) в `RangeBotEA`.
2. Совпадение числа сделок EA и Python на одном окне (допуск ±10%).
3. Независимый прогон на Exness: net R > 0 за 2025 и 90 дней 2026.
4. WFA: ≥60% активных фолдов в плюсе или 20+ форвард-сделок с положительным R.

До этого EURUSD остаётся только в research, не в live.

## Обновление: EURUSD возвращён в live

Причина прежнего минуса — не сама стратегия, а **другие границы H4 у Exness**
(сервер UTC+0 против UTC+2). `tools/range_feed_diag.py`, окно ~15 месяцев:

| Вариант (er=0/tp=3/trend=with) | Net R | Последние 60 дней |
|---|---:|---:|
| native как есть | +30.35 | −5.00 |
| native + H4 из M15 | +34.80 | −2.45 |
| Exness как есть | −6.95 | +5.50 |
| Exness +2h + H4 из M15 | **+11.70** | −6.30 |
| native M15 + Exness rebuilt H4 | +23.50 | +2.55 |

Native live-конфигурация даёт +30R за 15 месяцев; после пересборки H4 Exness
тоже в плюсе. Решение: **EURUSD снова в live** с `er=0/tp=3/trend=with`.
Условие: H4 должен быть согласован с M15; при переезде на другого брокера
H4 пересобирать. Последние 60 дней — просадка −5R, наблюдаем; при 20 сделках
в минусе — повторная ревизия.
