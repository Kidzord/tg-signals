# Лендинг после unslop · 2026-11-06

`unslop` (heydamir/unslop) — это skill/метод для Claude/Codex, не библиотека.
Применял его вручную: аудит → направление → проходы по типографике, цвету,
сетке, копи и деталям. Правил шаблон `tools/build_landing.py`, а не
`landing/index.html`: ночной job в 23:55 перезаписывает страницу из шаблона.

## Что было слопом

- заголовки весом 800, капс-лейблы с широкой разрядкой (`.18em`, `.08em`);
- четыре одинаковые карточки-стата, затем ещё три равных блока в каждом разделе;
- в шапке и мете «золото, форекс и **индексы**», хотя индексов в live нет;
- продукт не показан в герое: график лежал отдельной секцией;
- кнопки с радиусом 12 и `transition: all`;
- единственный акцент — золото — размазан по заголовкам карточек;
- на мобильном таблица из 4 колонок растягивала страницу.

## Направление

«Редакционный журнал»: спокойный графит, тёплая бумага текста, латунный акцент;
серифный заголовок, mono-цифры, hairline-разделители. Один акцент — primary CTA
и цифра результата; зелёный/красный только для P&L. Подпись: график R как
главный визуал, а не декоративный блок.

## Что изменено

- серифные `h1/h2`, вес 400; body 15/1.65, mono для чисел и R;
- график перенесён в герой, справа от текста; секция «Кривая результата» убрана;
- статы — одна ledger-полоса с hairline, а не четыре карточки;
- таблица без фона, колонка результата справа, tabular figures;
- шаги и методички — списки с hairline вместо карточек; золото только в номерах
  шагов и featured-тарифе;
- кнопки 46 px, радиус 8, press scale .98, transitions только color/border/transform;
- копи: «журнал сделок по золоту и форексу», без индексов; meta/OG обновлены;
- мобильный: на `<=560px` скрыта колонка «Сторона», таблица в scroll-контейнере,
  ledger в одну колонку; страница проверена в Chrome на 500 px (минимум окна
  headless Chrome на Windows; 390 px режется самим Chrome, не вёрсткой).

## Проверка

- `tests/test_landing.py` зелёный, весь набор **413 тестов**, `ruff` чистый;

- в HTML нет `text-transform: uppercase`, `font-weight:800`, широкой разрядки
  и упоминаний индексов.

## Карточки и сообщения (второй проход)

- `render.py`/`brand.py`: капс-лейблы `SIGNAL CARD`/`ACCOUNT PLAN`/`TRADE RESULT`/
  `REPORT`/`PLAN`/`PREMIUM SIGNALS` заменены на sentence case («Сигнал»,
  «План счёта», «Результат», «Отчёт», «План», «Сигналы»); `theme.spaced()` больше
  не используется в карточках.
- Бренд-карточки: «Золото · форекс · индексы» → «Золото · форекс» (индексов в
  live нет), аватар — `KidzordFX` без разрядки. `CARD_TITLE` теперь `KidzordFX`
  (18, semibold) вместо `KIDZORDFX` 20 bold.
- Иконки в hero-карточке приведены к одному приглушённому цвету вместо
  gold/purple/green; золото осталось акцентом цены/CTA.
- План: тело с 0.735, размер 13.5, ровнее заполняет карточку.
- Сообщения: из `voice.event_text`/`outcome_line` и `subbot.result_status`
  убраны эмодзи-статусы; заголовок плана 08:00 — без 🌅. Тексты остались
  вариативными (пулы `EVENT`/`INTRO`), просто без «бота по эмодзи».
