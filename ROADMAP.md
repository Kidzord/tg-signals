# ROADMAP — чего не хватает боту (составлен 2026-11-02)

Что уже работает: флот из 4 ботов (AUDUSD/USDCAD/EURUSD range, XAUUSD classic,
все прошли IS→OOS→WFA; classic работает без частичных фиксаций — 0/0 с
2026-11-03), премиум-бот (Stars + крипта, триал, рефералка, промокоды, nurture,
методички), бесплатная группа с задержкой 30 мин, дневник разработки в соцсетях
(план/итоги/TikTok/Threads в голосе автора), зеркало всего контента в личку,
outbox-доставка в SQLite, heartbeat + watchdog + dead-man switch, ночные бэкапы,
лендинг с авто-пересборкой. 256 тестов.

## B. Надёжность и деньги (неделя 1–2)

- [x] **B1. Портфельный kill-switch.** `risk_guard.py`: сумма R закрытых сделок
      с начала недели ≤ `PORTFOLIO_WEEK_LIMIT_R` (−6R) при ≥ 4 сделках → monitor.py
      пишет паузу до понедельника и шлёт алерт; bot.py не публикует новые входы
      (открытые сделки ведутся). Ручное снятие — `/guard resume` или
      `python risk_guard.py resume`, действует до конца недели.
- [x] **B2. Форвард-контроль с алертом.** Воскресный отчёт `forward` в 18:00:
      `tools/symbol_report.py` получил секцию «последние 20 сделок» и правило
      деградации (≤ −3R за 20 сделок) → в сообщении владельцу появляется
      «кандидат на отключение» и предложение убрать символ из `start_all.ps1`.
- [x] **B3. Учёба восстановлению из бэкапа.** `tools/restore.py`:
      `list` / `check` / `drill` / `restore --dest`. Проверяет integrity_check
      state.db, обязательные таблицы и JSON; `drill` разворачивает последний
      снимок в песочницу. Автозапуск — вс 18:10, при провале алерт владельцу.
- [x] **B4. Алерты о падении компонентов в Telegram.** monitor.py одним запросом
      получает список процессов и следит за subbot/autoposts/heartbeat/monitor/
      watchdog: нет дольше `COMPONENT_ALERT_MIN` (10 мин) → сообщение владельцу,
      возврат компонента — «снова на месте». Короткие перезапуски watchdog'а
      не спамят.
- [x] **B5. News-фильтр по экономкалендарю.** `news_calendar.py` тянет JSON
      ForexFactory (thisweek + nextweek), кэширует в `news_cache.json`, обновляет
      в фоновом потоке; bot.py не входит за `NEWS_BLOCK_BEFORE_MIN` (30) до и
      `NEWS_BLOCK_AFTER_MIN` (15) после красных событий валюты символа. При
      недоступном календаре — fail-open (прошлый кэш или вход разрешён), чтобы
      бот не замолчал.
