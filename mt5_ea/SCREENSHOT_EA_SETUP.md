# ScreenshotEA: скриншот терминала MT5

Советник делает PNG графика по запросу Python: открывает временный график
нужного символа/ТФ, рисует вход, стоп, цели и выход, вызывает
`ChartScreenShot` и сохраняет файл в `MQL5/Files`.

Пакет `MetaTrader5` для Python не умеет `ChartScreenShot`, поэтому обмен
идёт через файлы:

```
Python bot.py ──► MQL5/Files/kz_screenshot_request.txt
                         │
                         ▼
                 ScreenshotEA (OnTimer)
                         │
                         ▼
                 MQL5/Files/kz_shot_*.png
                         │
Python mt5_screenshot.py ◄┘ копирует в renders/ и отдаёт в Telegram
```

## Установка (уже сделана)

Скомпилированный `ScreenshotEA.ex5` лежит в:

```
C:\Program Files\MetaTrader 5\MQL5\Experts\ScreenshotEA.ex5
```

Если терминал в другом месте — скопируй `.ex5` в его `MQL5\Experts`.

## Как включить (один раз, руками)

1. Открой MetaTrader 5.
2. В Navigator (Ctrl+N) обнови список Expert Advisors (правый клик → Refresh).
3. Перетащи `ScreenshotEA` на любой график, например XAUUSD M15.
4. В окне свойств можно оставить всё по умолчанию. **Алго-трейдинг не нужен**:
   советник только читает файлы и делает скриншоты, сделок не открывает.
5. Нажми OK. В левом верхнем углу графика появится имя советника.

Советник сам открывает временные графики для нужного символа, поэтому
держать открытыми AUDUSD/USDCAD/XAUUSD не обязательно.

## Проверка

```bat
python mt5_screenshot.py check
```

Должно быть `ok: True` и свежий `heartbeat_age` (не больше 60 секунд).

Тестовая картинка:

```bat
python mt5_screenshot.py test
```

Файл появится в `renders\kz_shot_XAUUSD_*.png`.

## Как это работает при выходе сделки

`bot.py` при TP/SL/безубытке/закрытии по времени:

1. Проверяет heartbeat советника. Если его нет — сразу рисует свою карточку,
   без ожидания.
2. Пишет запрос с символом, ТФ, входом, стопом, целями, выходом и R.
3. Ждёт `kz_screenshot_done.txt` до 12 секунд.
4. Копирует PNG в `renders/` и отправляет в группу/premium.
5. Если советник не ответил — fallback на `render_trade_chart` (свечи по
   данным MT5, без окна терминала).

## Если терминал перезапустили

EA привязан к графику профиля. Если профиль сохранён, он поднимется сам.
Если нет — перетащи `ScreenshotEA` на график ещё раз и проверь
`python mt5_screenshot.py check`.

## Отключить

В `.env`:

```ini
MT5_SCREENSHOT=0
```

Тогда бот всегда использует свою карточку и не трогает терминал.
