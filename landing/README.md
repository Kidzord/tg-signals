# Лендинг KidzordFX

Статическая страница без сервера: `landing/index.html`. Всё внутри одного
файла — CSS и SVG-equity, никаких внешних зависимостей и секретов.

## Сборка

```bat
python tools\build_landing.py
```

Скрипт читает `trades.jsonl`, считает статистику через `track_record.py` и
перезаписывает `landing/index.html`. Автопосты делают это каждый день в 23:55.

## Деплой (2 минуты, без Git)

1. Открой [Cloudflare Pages](https://pages.cloudflare.com/) → **Create a project**
   → **Direct Upload**.
2. Перетащи папку `landing` целиком.
3. Получишь адрес вида `https://kidzordfx.pages.dev`.
4. Поставь его в bio Threads и TikTok.

Альтернатива: [Netlify Drop](https://app.netlify.com/drop) — тоже drag-and-drop.

Если хочешь свой домен — добавь его в Cloudflare Pages → Custom domains.

## Что на странице

* герой с позиционированием и двумя CTA (пробный доступ / бесплатная группа);
* сделки, итог в R, profit factor, максимальная просадка;
* SVG-кривая результата;
* последние 12 сделок, включая убыточные;
* «как это работает», цена, FAQ, дисклеймер.

Ссылки на бота идут с `?start=src_landing`, чтобы источник был виден в
атрибуции (`revenue.py` → `/revenue`).

## Важно

* Не добавляй в папку `.env`, токены и реальные номера счетов.
* Если сделок меньше 20, страница сама пишет, что выборка маленькая.
* Публикуем и стопы: это осознанная часть доверия, а не баг.
